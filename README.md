# Проект: Сравнение моделей машинного обучения для многоклассовой классификации

## Описание проекта
В данном проекте проводится полный цикл анализа данных и сравнения различных моделей машинного обучения на синтетическом датасете для задачи многоклассовой классификации.

### Разведочный анализ данных (EDA)
- Загрузка и первичный осмотр данных (400 строк, 7 признаков)
- Проверка пропусков и баланса классов (3 класса, сбалансированы)
- Описательная статистика и корреляционный анализ
- Визуализация корреляций с целевой переменной

### Предобработка данных
- Разделение на train/test 
- Анализ необходимости масштабирования
- Применение StandardScaler для моделей, требующих масштабирования

### Обучение моделей
Обучено 5 моделей машинного обучения:
- Logistic Regression (с масштабированием)
- K-Nearest Neighbors (с масштабированием)  
- Support Vector Machine (с масштабированием)
- Naive Bayes (без масштабирования)
- Decision Tree (без масштабирования)

### Оценка и сравнение
- Расчет метрик: Accuracy, F1-score (macro)
- Анализ переобучения (разница train/test accuracy)
- Визуализация результатов
- Выбор лучшей модели

## Характеристики датасета
- **Количество объектов:** 400
- **Количество признаков:** 6 (4 информативных, 2 неинформативных)
- **Количество классов:** 3
- **Баланс классов:** 33% на каждый класс
- **Seed:** 2026 (для воспроизводимости)

### Признаки:
1. `income_level` - информативный (большой масштаб)
2. `age_group` - информативный (средний масштаб)  
3. `credit_score_derived` - информативный (средний масштаб)
4. `debt_ratio_derived` - информативный (малый масштаб)
5. `zip_code` - неинформативный (шум)
6. `phone_area_code` - неинформативный (шум)

## Основные результаты анализа

### Важность масштабирования:
- **Обязательно:** Logistic Regression, KNN, SVM (различие в масштабах)
- **Не требуется:** Decision Tree, Naive Bayes

### Анализ переобучения:
- **Все модели стабильны** (переобучение ≤ 0.1)
- Наибольшая разница train/test: 
- Наименьшая разница: KNN (0.000), Naive Bayes (0.003)

### Лучшая производительность:
1. Support Vector Machine
2. Logistic Regression
3. K-Nearest Neighbors

## Метрики оценки
- **Accuracy** (точность)
- **F1-Score** (среднее F1 по всем классам)
- **Степень переобучения** (разница между train и test accuracy)
